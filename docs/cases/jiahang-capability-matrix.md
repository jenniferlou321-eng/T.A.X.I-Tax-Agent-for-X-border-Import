## 一、平台能力现状总览

| 状态 | 数量 | 占比 | 含义 |
|:--:|:--:|:--:|---|
| ✅ 已支持 | 2 / 18 | **11%** | Adapter + Channel + Validator 全部就绪,真实申报可用 |

## 三、P0 优先 — 平台 roadmap 上半年的三个核心税种

### 3.1 UK CT — 金额 £43,950 / 年

- **场景**:UK 子公司年度公司税申报,使用 3/200 边际救济公式
- **现状**:adapter 已在 `backend/jurisdictions/uk/corporation_tax/` 实现
- **缺失**:
  1. **GovTalk XML 客户端**(`hmrc_service.py` 当前用 `httpx` JSON 假路径,需改 XML 客户端 POST 到 `/api/xml/Corporation Tax Online`)
  2. **CT600 表单模板**(GovTalk 消息包装器,含 33+ 个 boxes)
  3. **3/200 边际救济计算器**(在 `calculator.py` 中确认/补全)
- **工作量**:2-3 周(1 名 senior backend + 1 名前端)
- **业务价值**:UK 所有客户**最大税种之一**,且 P0 必申报

### 3.2 CN VAT — 金额 ¥2,461,500 / 年

- **场景**:CN 母公司月度增值税申报
- **现状**:完全无 adapter
- **缺失**:
  1. **BrowserChannel**(Playwright 自动化电子税务局登录 + 申报)
  2. **销项/进项认证流程**(增值税专用发票认证抵扣)
  3. **多档税率决策**(13% 标准 / 9% 不动产 / 6% 现代服务 / 5% 简易 / 3% 征收率)
- **工作量**:4-6 周(1 名 senior + 1 名 QA + Playwright 维护)
- **业务价值**:中国所有客户**第一大税种**,月报频率高

### 3.3 CN CIT — 金额 ¥2,032,500 / 年

- **场景**:CN 母公司年度汇算清缴
- **现状**:完全无 adapter
- **缺失**:
  1. **季度预缴计算**(每季预缴,年度汇算清缴)
  2. **汇算清缴逻辑**(调增/调减项目,15+ 类)
  3. **暂性差异 DTA 计算**(嘉汉案例触发 4 类事件)
- **工作量**:4-6 周(1 名 senior + 复杂业务规则文档化)
- **业务价值**:中国所有客户**第二大税种**,且 DTA/DTL 是高级税务咨询

## 七、平台能力提升的 3 步走路径图

### Step A(0-3 月):Foundation

- BrowserChannel 基础架构
- ErpInvoiceTable 多币种 + 4 列升级
- UK CT adapter(XML 客户端)
- CN VAT adapter 基础版(Playwright)

### Step B(3-6 月):Coverage

- CN CIT adapter(汇算清缴 + DTA)
- UK PAYE & NIC(RTI XML)
- CN 境外税收抵免
- 关联申报基础

### Step C(6-12 月):Long Tail

- UK Import Duty / Business Rates / WHT supplementary
- CN 城建税 / 房产税 / 个税 / 印花税
- Pillar Two (BEPS 2.0) GloBE rules(集团收入 >€750M 时触发)
