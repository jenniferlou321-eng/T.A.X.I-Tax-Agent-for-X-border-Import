## 🔑 关键税种

### 1. 增值税 (VAT) - 主要税种

#### 一般纳税人 vs 小规模纳税人

| 项 | 一般纳税人 | 小规模纳税人 |
|----|-----------|-------------|
| 标准税率 | 13%, 9%, 6% | 3% (简易计税) |
| 销售额阈值 | 年销售额 ≥ 500 万元 | 年销售额 < 500 万元 |
| 进项抵扣 | 可以 | 不可以 |
| 发票开具 | 增值税专用发票/普通发票 | 普通发票 |
| 申报频率 | 月 | 季 |

#### 税率结构

| 税率 | 适用项目 |
|------|---------|
| **13%** | 销售/进口大部分货物（工业品）|
| **9%** | 粮食、食用植物油、图书、报纸、化肥等 |
| **6%** | 服务业、金融业、生活服务业等 |
| **3%** | 小规模纳税人简易计税 |
| **0%** | 出口货物（退/免税）|

### 2. 企业所得税 (CIT)

| 项 | 值 |
|----|-----|
| 一般税率 | 25% |
| 小型微利企业 | 5%-20% 优惠税率 |
| 高新技术企业 | 15% |
| 申报频率 | 季度预缴 + 年度汇算清缴 |

### 3. 个人所得税 (IIT)

- 综合所得：3%-45% 超额累进
- 经营所得：5%-35%
- 分类所得：利息/股息/红利/财产租赁等 20%
- 申报媒介：**自然人电子税务局** (etax.chinatax.gov.cn) 或 **个人所得税 APP**

## 🧮 中国增值税计算

### 一般纳税人 - 一般计税方法

```
应纳税额 = 当期销项税额 - 当期进项税额
销项税额 = 销售额 × 税率
进项税额 = 采购成本 × 税率 (凭增值税专用发票)
```

### 一般纳税人 - 简易计税（5% 征收率）

```
应纳税额 = 销售额 × 5% (或 3%)
销售额 = 含税销售额 / (1 + 征收率)
```

### 小规模纳税人

```
应纳税额 = 销售额 × 3%
销售额 = 含税销售额 / (1 + 3%)
```

### 计算示例：一般纳税人

**场景：2024 年 1 月**
- 销售货物（13% 税率）：¥1,130,000（含税）
- 销项税额 = 1,130,000 / 1.13 × 13% = ¥130,000
- 采购成本（13% 税率）：¥565,000（含税）
- 进项税额 = 565,000 / 1.13 × 13% = ¥65,000

| 项 | 销售额（含税）| 销售额（不含税）| VAT |
|----|--------------|--------------|-----|
| 销项 | 1,130,000 | 1,000,000 | 130,000 |
| 进项 | 565,000 | 500,000 | 65,000 |

**应纳税额 = 130,000 - 65,000 = ¥65,000**

### 出口退税计算

```
应退税额 = 出口货物离岸价 (FOB) × 退税率
当期不得免征和抵扣税额 = 当期出口货物离岸价 × 征退税率差
```

## 📡 申报媒介

### 电子税务局 (etax.chinatax.gov.cn)
- 主要申报平台
- 需企业实名认证
- 浏览器 + CA 证书（数字证书）
- 提供 API 但仅对企业税务师事务所开放

### 增值税发票综合服务平台
- 发票勾选认证
- 发票数据归集
- 出口退税审核

### 金税系统
- 国家税务总局后端
- 通过电子税务局与纳税人交互

### 自然人电子税务局
- 个人所得税申报
- 通过 **个人所得税 APP** 申报

## 🛡️ 合规要求

### 大数据税收监管
- 国家税务总局建立"金税四期"系统
- 发票流、资金流、合同流、货物流 四流合一
- 所有申报数据需可溯源、可比对

### 反避税
- BEPS 行动计划（中国是 G20 成员）
- 受控外国企业 (CFC) 规则
- 转让定价文档要求
- CRS (共同申报准则) 金融账户涉税信息交换

### 跨境电商
- 9610 模式：跨境电商 B2C 零售出口
- 9710 模式：跨境电商 B2B 直接出口
- 9810 模式：跨境电商出口海外仓
- 报关单与税务申报需匹配
